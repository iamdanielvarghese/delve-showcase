    Building Infinite Worlds: Procedural Terrain Generation

    The Problem

    Standard game environments are built by hand. For Delve, a Python-based exploration engine, the goal was to generate infinite, playable terrain dynamically. Random noise alone creates unnatural, scattered environments (like TV static). The challenge was generating contiguous, natural-looking biomes—mountains, plains, and oceans—that a player could actually navigate.

    The Algorithm: Perlin Noise

    To create natural geography, I utilized Perlin Noise. Unlike standard pseudo-random number generators, Perlin Noise calculates smooth, continuous gradients.

    By layering multiple "octaves" of noise and adjusting the frequency and amplitude, the algorithm generates a heightmap. This continuous mathematical output is then quantized into discrete grid tiles, mapping specific height thresholds to distinct biomes (e.g., deep water, sand, grass, rock).

    The Obstacle & The Fix: Dynamic Collision Mapping

    The Problem: Standard collision detection relies on static hitboxes drawn in the engine. Because Delve generates terrain infinitely using the noise algorithm, the environment is fundamentally dynamic. The core challenge was mapping the player's continuous pixel coordinates to the discrete, procedurally generated grid arrays in real-time. If the math was slightly off, the sprite would phase directly through generated mountains.

    The Solution: Instead of relying on brute-force hitbox overlaps, I implemented a predictive grid-mapping system. Before committing to a movement frame, the engine calculates the player's intended next position, translates it into a grid index, and queries the generated biomes array.
